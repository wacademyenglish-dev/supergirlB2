1. Used to (Past Habit)

We use used to + Base Verb for things that were true or habits in the past, but are NOT true today.

"I used to see two suns in the sky."

(Now I only see one sun on Earth.)

Your Turn:

When I was a child, I used to... I used to play _____, but now I don't have time.

2. Be used to (Current Normal)

We use Verb to Be + used to + ING/Noun to say that something is familiar, normal, and not strange anymore.

"She is used to flying."

(Flying is normal for her now. She is adapted.)

GRAMMAR ALERT

After "be used to", if you use an action, it MUST have -ING.

3. Get used to (The Process)

We use Get used to + ING/Noun to talk about the process of becoming familiar with something new. It means adapting.

"She is getting used to the yellow sun."

(It was strange at first, but she is slowly adapting to it right now.)
